# context/ — what the lane should already know

Durable background about ARCA's growth and operations, so an agent working a ticket does not have to be told
the same things every time. Positioning, ideal customer, voice, competitors, pricing rationale,
channel learnings.

Written by the founder (through the studio composer's `deposit_venture_file` tool, which opens a PR
here) or by hand. Indexed by the venture brain on ARCA's box, so the lane's research step can find a
fact by meaning rather than by filename.

One idea per file. Name the file after the idea, not the date.
